# 4.06 Kakao Login 기능 완성을 위한 추가작업

## 개요

NextAuth.js v5 + PrismaAdapter 기반으로 카카오 로그인 구조는 대부분 완성되어 있으나,
환경 설정 및 일부 코드 보완이 필요한 상태.

## 미완성 / 문제점

### 1. 환경변수 미설정 (필수)

`.env.local`에 아래 값이 실제로 채워져 있어야 함:

```env
KAKAO_CLIENT_ID=발급받은_REST_API_키
KAKAO_CLIENT_SECRET=발급받은_Client_Secret
NEXTAUTH_SECRET=랜덤값  # openssl rand -base64 32
```

---

### 2. 카카오 개발자 콘솔 Redirect URI 미등록 (필수)

[developers.kakao.com](https://developers.kakao.com) → 내 앱 선택 → 카카오 로그인 → Redirect URI 등록:

```
http://localhost:3000/api/auth/callback/kakao     ← 개발 환경
https://yourdomain.com/api/auth/callback/kakao    ← 프로덕션
```

> **참고:** 카카오 로그인 활성화도 반드시 ON으로 설정해야 함.

### 3. JWT callback에서 role을 DB에서 조회하지 않음 (버그)

**현재 코드** (`src/lib/auth.config.ts:26`):

```ts
async jwt({ token, user }) {
  if (user) {
    token.role = (user as { role?: string }).role || 'MEMBER'
    token.id = user.id
  }
  return token
}
```

**문제:**

- 카카오 OAuth user 객체에는 `role` 필드가 없음
- 이후 재방문 시 `user`가 전달되지 않아 token이 유지되지만, **최초 로그인 시 role이 항상 'MEMBER'로 설정됨**
- 관리자가 카카오로 로그인하면 role이 'MEMBER'로 덮어써지는 버그 발생

**수정 방법** (`src/lib/auth.ts`의 callbacks 오버라이드):

```ts
import { prisma } from '@/lib/prisma'

// auth.ts의 NextAuth 설정에서 callbacks 확장
callbacks: {
  async jwt({ token, user, account }) {
    if (account && user) {
      // 최초 로그인 시 DB에서 실제 role 조회
      const dbUser = await prisma.user.findUnique({
        where: { id: user.id },
        select: { role: true },
      })
      token.role = dbUser?.role ?? 'MEMBER'
      token.id = user.id
    }
    return token
  },
  // ...기존 session callback 유지
}
```

### 4. 카카오 이메일 미제공 케이스 미처리 (잠재적 오류)

**문제:**

- 카카오 사용자가 이메일 제공에 동의하지 않으면 `email = null`로 들어옴
- `prisma/schema.prisma`의 `User.email`은 `String @unique` (NOT NULL)
- PrismaAdapter가 `null` 이메일로 User 생성 시도 → DB 오류 발생

**해결 방법 (택1):**

**A. 이메일 필수 동의 강제** — 카카오 개발자 콘솔에서 이메일을 필수 동의 항목으로 설정

**B. 폴백 처리** — auth.ts의 `signIn` callback에서 이메일 없는 경우 차단 또는 임시 이메일 생성:

```ts
callbacks: {
  async signIn({ user, account }) {
    if (account?.provider === 'kakao' && !user.email) {
      // 이메일 없는 카카오 계정 로그인 차단
      return '/login?error=EmailRequired'
    }
    return true
  },
}
```

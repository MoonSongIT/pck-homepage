```
현재 상태                          목표 상태
┌─────────────────────┐          ┌─────────────────────┐
│ paxchristikorea.org │          │ paxchristikorea.org │
│ → Clickn 서버        │   ──▶   │ → Verce 서버        │
│   139.150.65.235    │          │   76.76.21.21       │
└─────────────────────┘          └─────────────────────┘     Inames 등록                      Inames 등록 유지
     가비아 DNS 관리                   가비아 DNS 레코드 변경
```

### 이전 방식: DNS 포인팅 변경 (도메인 이전 없이)

도메인 등록업체(Inames)를 변경할 필요 없이, **가비아 DNS 레코드만 수정**하면 됩니다.

```
변경 전: A 레코드 → 139.150.65.235 (Clickn)
변경 후: A 레코드 → 76.76.21.21    (Vercel)
```

## 3. 기존 도메인 관리자에게 요구할 사항

### 3-1. 필수 요구 사항 (반드시 확보)

#### A. 가비아 DNS 관리 권한

```
요구 내용:
  ① 가비아 계정 로그인 정보 (ID/PW) 직접 이관
     또는
  ② 가비아 DNS 관리 패널 접근 권한 공유
     또는
  ③ 관리자가 직접 DNS 레코드 변경 작업 수행

접근 경로: gabia.com → My 가비아 → 서비스 관리 → DNS 관리
         → paxchristikorea.org [설정] → DNS 레코드 관리
```

#### B. 현재 DNS 레코드 전체 백업

```
요구 내용:
  - DNS 관리 패널의 전체 레코드 목록 스크린샷 또는 내보내기
  - 특히 MX 레코드 (이메일 서비스 관련) 확인 필수
  - TXT 레코드 (SPF, DKIM 등) 확인 필수

이유: 웹사이트 DNS만 변경하고, 이메일 관련 레코드는 보존해야 함
```

#### C. 도메인 등록 계정(Inames) 정보

```
요구 내용:
  - Inames 계정 로그인 정보 또는 계정 이관
  - 도메인 등록자(Registrant) 연락처 정보
  - 도메인 만료일 확인 (갱신 일정 파악)
  - 도메인 자동갱신 설정 여부

이유: 도메인 만료 시 갱신 처리를 위해 필요
```

### 3-2. 선택 요구 사항 (가능하면 확보)

#### D. 기존 Clickn 호스팅 정보

```
요구 내용:
  - Clickn 관리자 계정 정보
  - 기존 콘텐츠 백업 (게시물, 이미지 등)
  - 기존 사이트의 URL 구조 목록 (301 리다이렉트 설정용)

이유: SEO 유지를 위한 리다이렉트 매핑 및 콘텐츠 마이그레이션
```

#### E. 연결된 외부 서비스 목록

```
요구 내용:
  - 이메일 서비스 사용 여부 및 제공업체
    (예: @paxchristikorea.org 이메일이 있는지)
  - Google Search Console / Analytics 설정 여부
  - 기타 도메인과 연결된 서비스 목록

이유: DNS 변경 시 기존 서비스 중단 방지
```

## 4. DNS 전환 절차 (권한 확보 후)

### 4-1. 전환 전 준비

- [ ] 가비아 DNS 관리 패널 접근 확인
- [ ] 기존 DNS 레코드 전체 백업 (스크린샷 저장)
- [ ] MX 레코드 존재 여부 확인 (이메일 서비스)
- [ ] TXT 레코드 확인 (SPF, DKIM, Resend 등)
- [ ] Vercel에서 새 사이트 정상 동작 확인 (`pck-homepage.vercel.app`)
- [ ] 전환 시간대 결정 (트래픽 적은 시간, 권장: 화~목 새벽 2시)

### 4-2. Vercel 도메인 등록

```
1. Vercel 대시보드 → pck-homepage 프로젝트
2. Settings → Domains
3. paxchristikorea.org 입력 → Add
4. www.paxchristikorea.org 입력 → Add (www → non-www 리다이렉트)
```

### 4-3. 가비아 DNS 레코드 변경

```
접속: gabia.com 로그인 → My 가비아 → 서비스 관리
     → DNS 관리 → paxchristikorea.org [설정]

변경할 레코드:
  ┌──────────────────────────────────────────────────┐
  │ [삭제] 기존 웹 관련 A 레코드                        │
  │   A    @    139.150.65.235                       │
  │                                                  │
  │ [추가] Vercel 연결 레코드                           │
  │   A      @      76.76.21.21           TTL: 300   │
  │   CNAME  www    cname.vercel-dns.com  TTL: 300   │
  │                                                  │
  │ [유지] 절대 삭제하지 말 것                           │
  │   MX 레코드 (이메일 관련) → 그대로 유지              │
  │   TXT 레코드 (SPF, DKIM) → 그대로 유지              │
  │   Resend 관련 레코드 → 그대로 유지                   │
  └──────────────────────────────────────────────────┘
```

### 4-4. 전환 후 확인

```
DNS 전파 확인:
  nslookup paxchristikorea.org
  → 76.76.21.21 응답 시 전파 완료 (보통 10분~1시간)

SSL 인증서:
  → Vercel이 Let's Encrypt 인증서를 자동 발급 (수 분 소요)
```
